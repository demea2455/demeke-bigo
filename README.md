# Demeke Bingo (`demeke-bigo`)

A web-based Bingo application created by **Demeke** (`demea2455`).

## Live Demo
Once GitHub Pages is enabled on the `main` branch, you can access the page at:
- `https://demea2455.github.io/demeke-bigo/`

## Features
- Interactive Bingo web experience (`demeke_bingo.html` / `index.html`)
- Accessible directly in a mobile or desktop web browser

## How to Run Locally
1. Clone or download the repository.
2. Open the HTML file in any web browser.
